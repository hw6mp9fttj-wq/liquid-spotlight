# 聚焦搜索 · Liquid Glass

用 iOS 27 的液态玻璃（Liquid Glass）材质做的一块**聚焦搜索面板**。单文件 HTML，打开即用，没有构建步骤、没有外部依赖、不联网也能跑。

![材质](https://img.shields.io/badge/material-Liquid%20Glass-9fe9ff) ![单文件](https://img.shields.io/badge/build-none-success) ![License](https://img.shields.io/badge/license-MIT-black)

## 它是什么

只有一块玻璃。没有桌面、没有菜单栏、没有 Dock，也不是在模仿某个系统的界面——就是 Spotlight 那个最核心的东西：一个输入框，加一份随时更新的结果列表。

背后是一片被它折射的彩色光（青绿、蓝紫、暖橙三层渐变 + 一道斜向光带 + 颗粒噪点）。玻璃需要有东西可折射才像玻璃，所以背景存在；但它只负责当背景，不冒充桌面壁纸。

## 功能

- **实时结果**：输入即出结果，按类别分组；空态给「最近搜索」与几条可点的示例。
- **表达式计算**：`128 * 7 + sqrt(2)`、`(1+2)^3`、`12% * 80`、`√9`，支持括号、乘方、百分比、开方；全角符号和「计算一下」「等于多少」会被归一化。
- **单位换算**：`12 厘米 换算 英寸`、`72kg 磅`、`100 华氏度 摄氏度`、`1.5GB MB`，覆盖长度、重量、数据、时间、温度（C / F / K）。
- **复制结果**：选中计算或换算结果按 `↩`，直接进剪贴板（带兜底实现，非安全上下文也能用）。
- **网页搜索**：列表末尾始终保留一条 Bing 搜索，回车在新标签页打开；本地没有命中时会标出「本地无命中」。
- **深浅外观**：底栏按钮，或输入「切换外观 / 主题 / theme」从结果里切换，记在 localStorage。
- **记忆**：搜索历史与外观都会持久化。
- **键盘优先**：`↑` `↓` 选择、`↩` 执行、`esc` 清空重输、`⌘⌫` 清空、`⌘K` 回到输入框；焦点不在输入框时敲任意字符会自动接上。
- **响应式**：宽屏是左结果右预览的两栏玻璃；窄屏自动收成单栏卡片，输入框 16px 起，避免移动端缩放。

## 键盘

| 按键 | 作用 |
| --- | --- |
| 直接输入 | 任意可打印字符自动聚焦输入框 |
| `↑` `↓` | 在结果间移动，右侧预览同步 |
| `↩` | 执行选中项（复制结果 / 打开网页 / 切换外观） |
| `esc` | 清空并重新输入 |
| `⌘⌫` / `Ctrl ⌫` | 清空 |
| `⌘K` / `Ctrl K` | 回到输入框 |

## 液态玻璃是怎么做的

没有贴图，全部由 CSS 分层合成，六层叠出厚度：

1. **底材**：`backdrop-filter: blur() saturate() brightness()`，面板真正吸住背后的光，模糊量、饱和、亮度都挂在变量上。
2. **染色**：158° 白色渐变 + 顶部径向提亮，模拟玻璃对环境的自适应色偏，底层再垫一层半透明深色墨。
3. **镜面高光边**：`conic-gradient` 画一圈光，用 `mask-composite` 只留下 1.4px 描边——上缘最亮、转角连成光弧，随 `--spec` 变强弱。
4. **边缘色散**：第二圈更宽的 conic（青 / 品 / 黄）`blur(4px)` 后压在边缘，模拟厚玻璃折射分解出的彩边，强度由 `--disp` 控制。
5. **油膜高光**：跟随指针的径向高光，`mix-blend-mode: screen` 叠在最上层，玻璃会随视线流动。
6. **颗粒**：`feTurbulence` 生成的噪点以 overlay 混合，避免玻璃显得像塑料。

面板圆角、模糊与两档光学参数都在 CSS 变量上（`--blur` `--spec` `--disp`），改一处即可整体换质感。

## 运行

```bash
git clone https://github.com/hw6mp9fttj-wq/liquid-spotlight.git
cd liquid-spotlight
open index.html      # macOS；Windows / Linux 直接双击 index.html
```

也可以把仓库 Settings → Pages 打开（Source 选 `main` / root），得到一个在线可访问的版本。

## 真实与示例

- **真实**：计算、单位换算、复制、网页搜索、外观切换、历史记录（浏览器 localStorage）。
- **示例**：空态里那几条「可以试试」的提示词是示范入口，点一下就把内容填进输入框，不代表任何本机数据。
- 不读取本地文件、不索引邮件或日程——那些需要系统权限的能力，单文件网页拿不到，这里就没有假装有。
